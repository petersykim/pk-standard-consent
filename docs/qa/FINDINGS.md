| C-002 | pk-standard-consent | Da11y Accessibility | S3 | The shared `@pk/ui` `<Switch>` component (`_shared/ui/src/components/Field.tsx`) accepted an `aria-label` prop at every consent admin call site (8 total: Settings.tsx x4, RegionsTable.tsx x3, CookieScan.tsx x1) but `SwitchProps` never declared it and the component never forwarded it to the underlying `<input>` -- every one of these switches had ZERO accessible name.
